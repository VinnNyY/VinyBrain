# Motivo da Reprovação - Lote 02

## Data

2026-07-06

## Motivo da reprovação

O Lote 02 foi reprovado porque alguns tutoriais puxavam o cliente para o cPanel sem necessidade, deixando o fluxo técnico demais para a seção Painel Novo.

## Exemplos do problema

- o tutorial de armazenamento começou no Painel Novo, mas misturou uma saída técnica para o cPanel;
- o tutorial de SSL depende de navegação técnica fora do fluxo simples do Painel Novo;
- o tutorial de filtros também caminhou para uma área mais técnica do que o cliente leigo precisa para um tutorial simples.

## Regra nova aprendida

Se uma ação pode ser feita pelo Painel Novo, o tutorial não deve mandar o cliente entrar no cPanel.

Tutorial da seção Painel Novo deve priorizar o caminho mais simples, visual e direto para cliente leigo.

cPanel só entra quando o recurso não existir no Painel Novo ou quando o tutorial for explicitamente sobre cPanel.

## O que evitar nos próximos lotes

- qualquer tutorial que exija cPanel sem necessidade real;
- qualquer fluxo longo demais para cliente leigo;
- qualquer passo que dependa de configuração sensível ou risco de quebra;
- qualquer tutorial que pareça documento interno ou manual técnico;
- qualquer artigo que não tenha print claro e fácil de entender.

## Próxima direção

Os próximos temas devem ser 100% Painel Novo, curtos, diretos e seguros, com foco em navegação, suporte, faturas, chamados, serviços e ajuda básica.
