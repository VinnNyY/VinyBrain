<p>Localizar a área de Deploy no Painel Novo StayCloud é útil para quem quer saber onde ficam as opções de publicação de projetos, histórico de deployments, logs, domínios, integrações e plano do Cloud. Este tutorial mostra apenas como encontrar a área e reconhecer os principais itens da tela, sem iniciar um deploy.</p>

<h2>Quando localizar a área de Deploy no Painel Novo StayCloud</h2>
<p>Use este guia quando você quiser entender onde fica o recurso de Deploy, confirmar se a área Cloud aparece na sua conta ou identificar quais abas estão disponíveis antes de seguir para um tutorial específico. A orientação é de consulta. Não clique em botões de ativação, novo projeto ou publicação se você não pretende iniciar um fluxo real.</p>
<p>Na conta validada, o menu <strong>Deploy</strong> abre a área <strong>Cloud</strong>. A tela pode indicar que o Cloud ainda não está ativo. Mesmo assim, ela mostra informações úteis sobre o recurso e os caminhos internos que estarão disponíveis quando a função for utilizada.</p>

<h2>Antes de começar</h2>
<ul>
  <li>Tenha acesso ao Painel Novo da StayCloud.</li>
  <li>Confirme que está na conta correta.</li>
  <li>Use este tutorial somente para localizar a área.</li>
  <li>Não clique em <strong>Começar grátis</strong>, <strong>Novo projeto</strong> ou qualquer ação de publicação sem orientação específica.</li>
</ul>

<h2>Como encontrar a área de Deploy</h2>

<h3>1. Localize o menu Deploy</h3>
<p>Depois de entrar no Painel Novo, observe o menu lateral esquerdo. A opção <strong>Deploy</strong> aparece junto das demais áreas da conta, como Hospedagem, VPS, Loja, Domínios, Faturas e Suporte. Clique em <strong>Deploy</strong> apenas para abrir a área de consulta.</p>
<figure>
  <img src="prints-finais/01-menu-deploy-sanitizado.png" alt="Menu Deploy destacado para localizar a área de Deploy no Painel Novo StayCloud.">
  <figcaption>O menu Deploy é a entrada para a área Cloud dentro do Painel Novo.</figcaption>
</figure>

<h3>2. Confira a tela Cloud</h3>
<p>Ao abrir o menu, o painel carrega a área <strong>Cloud</strong>. No topo ou na lateral interna, você pode ver abas como <strong>Visão geral</strong>, <strong>Deployments</strong>, <strong>Logs</strong>, <strong>Domínios</strong>, <strong>Integrações</strong> e <strong>Plano</strong>. Essas abas indicam onde ficarão as informações de publicação, acompanhamento e configuração.</p>
<figure>
  <img src="prints-finais/02-area-cloud-deploy-sanitizado.png" alt="Área Cloud aberta com abas da área de Deploy no Painel Novo StayCloud.">
  <figcaption>A tela Cloud organiza as seções relacionadas ao Deploy.</figcaption>
</figure>

<h3>3. Verifique o status antes de avançar</h3>
<p>Se aparecer a mensagem <strong>Cloud ainda não ativo</strong>, isso significa que a área está disponível para consulta, mas não há um Cloud ativo nessa conta. Nesse caso, não avance em botões de ativação se o objetivo é apenas localizar a área.</p>
<figure>
  <img src="prints-finais/03-cloud-ainda-nao-ativo-sanitizado.png" alt="Mensagem Cloud ainda não ativo na área de Deploy do Painel Novo StayCloud.">
  <figcaption>O status ajuda a entender se a área já está ativa ou se ainda depende de uma etapa adicional.</figcaption>
</figure>

<h2>O que você encontra na área de Deploy</h2>
<p>A área pode apresentar uma visão geral do Cloud, histórico de publicações em Deployments, registros em Logs, domínios vinculados ao projeto, integrações e informações de plano. A disponibilidade de cada seção pode variar conforme o estado da conta e do serviço.</p>
<p>Se a conta ainda não tiver Cloud ativo, a tela pode exibir materiais de orientação e botões de ativação. Eles não precisam ser usados para concluir este tutorial. A meta aqui é apenas reconhecer onde a área fica.</p>

<h2>O que não fazer neste tutorial</h2>

  <li>Não ativar Cloud sem necessidade real.</li>
  <li>Não conectar GitHub, GitLab ou outra integração.</li>
  <li>Não adicionar domínio ao Cloud.</li>

<h2>Dúvidas frequentes</h2>
<h3>Deploy e Cloud são a mesma área?</h3>
<p>No Painel Novo validado, o menu se chama Deploy e a tela aberta se identifica como Cloud. Por isso, o usuário pode ver os dois nomes no mesmo fluxo.</p>
<h3>Posso clicar em Começar grátis?</h3>
<p>Somente se você realmente quiser iniciar a ativação do Cloud. Este tutorial não orienta essa etapa.</p>
<h3>O que significa Cloud ainda não ativo?</h3>
<p>Significa que a área foi localizada, mas ainda não há um Cloud ativo para a conta consultada.</p>

<h2>Conclusão</h2>
<p>Você pode localizar a área de Deploy no Painel Novo StayCloud pelo menu lateral e confirmar a tela Cloud sem iniciar nenhuma publicação. Antes de avançar para um fluxo de deploy real, confira o status da área e siga apenas um tutorial específico para essa ação.</p>
