# Plano de Prints

Tutorial: Como usar a busca geral do Painel Novo da StayCloud

## Objetivo visual

Mostrar como usar a busca superior do Painel Novo para localizar itens da conta sem executar alterações nos resultados encontrados.

## Regras de captura

- Cada print deve ter somente um alvo principal.
- O texto do passo deve corresponder exatamente ao elemento marcado.
- O próximo passo deve confirmar o resultado da ação anterior.
- Não marcar botão próximo, banner, notificação, menu não usado ou elemento decorativo.
- A marcação não pode cobrir texto do campo, resultado, título, ícone necessário ou elemento clicável.

## Sanitização obrigatória

Censurar ou substituir:

- domínio;
- e-mail;
- nome;
- fatura;
- ID;
- valores;
- chamado;
- dados da conta.

## Escopo

Este tutorial é somente de consulta e navegação. Não executar alterações nos itens encontrados.
