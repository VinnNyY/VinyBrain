# Para publicar no WordPress

Abra:

`01 - PUBLICAR - TITULO WORDPRESS.txt`

Copie o título e cole no campo de título do WordPress.

Abra:

`02 - PUBLICAR - CODIGO HTML CORPO.txt`

Copie todo o conteúdo.

No WordPress, abra “Visualizar como código” ou “Editor de código”.

Cole o código no corpo.

As imagens já estão incorporadas por URLs públicas.

Não é necessário inserir imagens manualmente.

Preencha o Rank Math usando:

`04 - SEO RANK MATH COMPLETO.txt`

Nunca use o Markdown editorial antigo no WordPress.
