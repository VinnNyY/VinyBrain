# Fonte Editorial

## Objetivo

Ensinar o cliente a localizar os registros ou dados DNS de uma hospedagem no Painel Novo da StayCloud para consultar as informações necessárias em plataformas externas, como Cloudflare, Registro.br ou outro provedor de DNS.

## Escopo permitido

- Acessar a hospedagem correta.
- Identificar a aba `DNS`.
- Consultar os dados ou registros exibidos.
- Entender campos como tipo, nome/host, valor/destino e TTL quando eles existirem na interface real.
- Explicar que a informação consultada pode servir de referência para configuração no provedor que administra o DNS autoritativo.

## Fora do escopo

- Criar registro DNS no StayPanel.
- Criar registro A no cPanel.
- Alterar nameservers.
- Comprar domínio.
- Adicionar domínio.
- Configurar Cloudflare do início ao fim.
- Alterar registros DNS reais dentro da StayCloud.
- Orientar cópia indiscriminada de MX, SPF, DKIM, DMARC, CNAME ou TXT.

## Decisão de título

Título escolhido: `Como localizar os registros DNS no Painel Novo da StayCloud`.

Motivo: a evidência local disponível indica uma aba `DNS` com área de registros DNS. A validação atual da tela ainda precisa ser refeita antes da publicação; se a tela atual mostrar principalmente dados de apontamento, o título deve ser reavaliado para `Como consultar os dados de DNS no Painel Novo da StayCloud`.
