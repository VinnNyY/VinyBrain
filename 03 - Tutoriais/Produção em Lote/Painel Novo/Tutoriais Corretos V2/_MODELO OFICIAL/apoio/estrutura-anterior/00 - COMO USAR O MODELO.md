# Como usar o modelo oficial

Copie esta pasta para criar um tutorial dentro de `Tutoriais Corretos V2`.

Todo novo tutorial deve possuir:

- título separado
- corpo em HTML puro
- versão completa com um H1
- SEO completo
- pacote completo
- preview
- relatório de validação
- checklist
- `midias-publicas.json`
- prints finais sanitizados
- validação automática

Substitua todos os campos do modelo. Um pacote com placeholders não está pronto.
