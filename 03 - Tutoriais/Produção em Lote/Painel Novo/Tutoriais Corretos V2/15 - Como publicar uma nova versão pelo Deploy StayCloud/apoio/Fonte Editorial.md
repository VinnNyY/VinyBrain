## Decisões editoriais

- Usar `publicar nova versão` no título porque o usuário está atualizando um projeto já conectado.
- Explicar que o painel usa `novo deploy`, mas o comando validado para projeto conectado é `npx @staysdev/setup deploy`.
- Não prometer rollback, zero downtime, cache automático ou versionamento avançado.
- Não aprofundar logs, domínio personalizado, variáveis ou troubleshooting.
