# Fonte Editorial

Tema: Como alterar a cota de armazenamento de uma conta de e-mail no Painel Novo da StayCloud

Status: não produzido como tutorial.

## Evidências

- A categoria pública Painel novo foi auditada em 2026-07-28.
- A base pública possui artigo de alteração de armazenamento pelo cPanel.
- A base pública possui artigo de criação de e-mail no Painel Novo, que trata de cota durante a criação.
- A base pública possui artigo de consulta de uso/cota no Painel Novo.
- O Painel Novo validado na conta autorizada exibiu a conta descartável, mas não exibiu ação de edição de cota.

## Decisão editorial

Não criar tutorial falso de alteração de cota no Painel Novo.

O tema deve permanecer registrado como recurso indisponível no Painel Novo validado. Se a StayCloud liberar um botão de edição de cota no futuro, o tema deve passar novamente por auditoria de duplicação e validação real antes de qualquer produção.

## Observações de segurança

- Nenhuma conta real foi alterada.
- Nenhuma conta foi excluída.
- Uma conta descartável foi criada para teste quando nenhuma conta `tutorial-teste-*` estava visível.
- Nenhuma senha foi registrada.
- Nenhum dado sensível deve ser publicado.
