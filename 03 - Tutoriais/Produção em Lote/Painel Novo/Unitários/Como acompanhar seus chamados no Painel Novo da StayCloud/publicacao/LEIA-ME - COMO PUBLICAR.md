# Forma recomendada

1. Copie o conteúdo de:
   `PUBLICAR NO WORDPRESS - TITULO.txt`

2. Cole no campo de título do WordPress.

3. Abra “Visualizar como código” ou “Editor de código”.

4. Copie integralmente:
   `PUBLICAR NO WORDPRESS - CORPO SEM TITULO.md`

5. Cole no corpo do artigo.

As imagens já estão inseridas no código usando URLs públicas. Não é necessário inserir prints manualmente.

# Forma alternativa — tudo em uma única colagem

Copie:

`PUBLICAR NO WORDPRESS - COMPLETO COM TITULO.md`

Essa versão inclui o título como `<h1>` dentro do corpo.

Atenção:

Essa alternativa não preenche o campo de título nativo do WordPress. Para SEO, slug, BetterDocs e organização do artigo, a forma recomendada é utilizar o título separado e o corpo sem `<h1>`.

# Regra máxima

Nunca utilizar o Markdown editorial antigo no WordPress.

Os arquivos `.md` desta pasta de publicação contêm HTML puro e foram criados apenas para facilitar a cópia.
