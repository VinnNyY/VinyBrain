# Checklist de Tutorial

Este checklist ajuda a revisar um tutorial antes de salvar ou publicar.

## Estrutura

- [ ] O título está claro
- [ ] O objetivo está definido
- [ ] O público-alvo faz sentido
- [ ] Os pré-requisitos estão listados
- [ ] O passo a passo está completo
- [ ] A ordem dos passos está correta
- [ ] O resultado esperado está descrito
- [ ] A linguagem está em tom de cliente final

## Clareza

- [ ] O texto está simples e direto
- [ ] Não há termos confusos sem explicação
- [ ] Não há informações desnecessárias
- [ ] O texto mantém tom natural e profissional
- [ ] O texto não parece instrução interna

## Precisão

- [ ] Não há dados inventados
- [ ] As instruções estão coerentes
- [ ] Os nomes de sistemas e ferramentas estão corretos
- [ ] Os passos refletem a prática real

## Visual

- [ ] Os prints são reais
- [ ] Os prints mostram onde clicar ou o que conferir
- [ ] As marcações visuais são claras
- [ ] Não há placeholders
- [ ] Não há dados sensíveis

## Revisão final

- [ ] Ortografia revisada
- [ ] Formatação organizada
- [ ] Exemplos revisados
- [ ] Pronto para uso
