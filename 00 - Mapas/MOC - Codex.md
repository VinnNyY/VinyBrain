## Uso previsto

- Ler antes de iniciar tarefas no vault.
- Consultar quando a sessao estiver longa ou confusa.
- Usar como porta de entrada para regras, seguranca e historico.
- Consultar `Skills instaladas` quando houver skill nova, ajuste de escopo ou revisão do conjunto ativo.

## Fluxo rapido

1. Ler `Regras do Codex`.
2. Ler `Contexto do Trabalho`.
3. Abrir `Protocolo de Sessao`.
4. Copiar `Prompt de Inicializacao`, se quiser iniciar rapido.
5. Conferir `Checkpoint Atual` antes de seguir em uma tarefa que ja vinha andando.
6. Abrir o `Painel Operacional - Viny Brain` para uma leitura rapida do estado geral.
7. Consultar `Viny Flow` quando a tarefa pedir orquestracao, agentes, workflows ou checklists.

## Regra de uso

- Este mapa deve apontar para regras, nao para improviso.
- Se surgir um novo padrao operacional recorrente, registrar primeiro no vault e depois ligar aqui.
