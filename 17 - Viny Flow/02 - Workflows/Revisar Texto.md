# Revisar Texto

## 1. Objetivo

Documentar o processo para revisar textos soltos, mantendo a intenção original, corrigindo português, melhorando clareza e ajustando o tom para o destino correto.

## 2. Quando usar

Use este workflow quando houver:

- texto bruto para revisar;
- mensagem para cliente, coordenação, equipe interna, candidato ou comunicado;
- relatório ou aviso que precise de melhor escrita;
- texto que esteja correto no conteúdo, mas fraco em clareza, tom ou organização;
- necessidade de uma versão pronta para uso sem perder a intenção original.

## 3. Entrada esperada

- texto bruto;
- público-alvo;
- tom desejado;
- contexto;
- destino da mensagem.

## 4. Agentes envolvidos

- **Agente Redator**: corrige, reescreve e melhora a fluidez do texto.
- **Agente Auditor**: confere se a revisão mantém coerência, sentido e estrutura.
- **Agente Segurança**: valida que não há dado sensível ou informação indevida.

## 5. Etapas

### Identificar público-alvo

1. Descobrir para quem o texto será enviado.
2. Ajustar o nível de formalidade ao público.

### Entender intenção

1. Identificar o objetivo real da mensagem.
2. Preservar a intenção original sem exagerar na reescrita.

### Corrigir português

1. Ajustar ortografia.
2. Corrigir concordância.
3. Corrigir pontuação quando necessário.

### Melhorar clareza

1. Simplificar frases longas.
2. Organizar ideias em sequência mais natural.
3. Remover ambiguidade.

### Ajustar tom

1. Alinhar o texto ao destino da mensagem.
2. Tornar a leitura mais natural e adequada ao contexto.

### Remover excesso de formalidade

1. Cortar frases excessivamente burocráticas.
2. Evitar rigidez desnecessária.

### Manter a intenção original

1. Não alterar o sentido central.
2. Não inventar detalhes.

### Validar se não há dado sensível

1. Verificar se o texto expõe credenciais, dados pessoais ou informações internas indevidas.
2. Remover qualquer conteúdo sensível antes da entrega.

### Entregar versão pronta para uso

1. Consolidar a revisão final.
2. Garantir que o texto possa ser usado sem nova reescrita.

## 6. Variações de tom

- cliente;
- coordenação;
- equipe interna;
- candidato;
- comunicado;
- relatório.

## 7. Critérios de aprovação

O workflow está aprovado quando:

- o texto ficou claro;
- o português foi corrigido;
- o tom está adequado ao destino;
- a intenção original foi preservada;
- não há dado sensível;
- a versão final está pronta para uso.

## 8. Critérios de reprovação

Reprovar quando houver:

- alteração indevida de sentido;
- excesso de formalidade;
- texto confuso ou truncado;
- português ainda com erro relevante;
- tom incompatível com o destinatário;
- dado sensível exposto;
- saída ainda não pronta para uso.

## 9. Checklist final

- [ ] Público-alvo identificado
- [ ] Intenção entendida
- [ ] Português corrigido
- [ ] Clareza melhorada
- [ ] Tom ajustado
- [ ] Excesso de formalidade removido
- [ ] Intenção original preservada
- [ ] Segurança validada
- [ ] Versão final pronta

## 10. Prompt reutilizável para revisar texto

`Siga o workflow Revisar Texto. Revise este texto para o público-alvo indicado, corrija português, melhore clareza e tom, preserve minha intenção original e remova qualquer dado sensível.`
