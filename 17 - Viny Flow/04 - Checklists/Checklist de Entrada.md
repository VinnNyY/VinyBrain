# Checklist de Entrada

- Objetivo confirmado.
- Escopo definido.
- Arquivos de contexto lidos.
- Fonte de verdade definida.
- Workflow escolhido.
- Agentes envolvidos listados.
- Risco principal identificado.
- Arquivos autorizados para alteracao listados.
- Arquivos proibidos de alteracao listados.
- Restricoes sensiveis confirmadas.
- Skills locais relevantes verificadas.
- Necessidade de atualizar historico ou checkpoint confirmada.
- Historico ou checkpoint aberto, se necessario.
