# Auditorias de Governança

Esta pasta guarda os relatórios de auditoria geral do `Viny Brain`.

## Uso

- registrar revisões estruturais do vault;
- guardar diagnósticos de organização e conexões;
- anotar riscos, duplicações e índices desatualizados;
- centralizar relatórios produzidos pelo `Agente Governança do Viny Brain`.

## Regra

Nada nesta pasta deve ser movido, apagado ou reescrito sem aprovação explícita.
