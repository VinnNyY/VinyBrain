# Viny Flow

Viny Flow e a camada de orquestracao do `Viny Brain` inspirada no estudo do Ruflo, mas sem instalar Ruflo.

## Principios

- Nao usa daemon.
- Nao usa hooks agressivos.
- Nao usa MCP como dependencia central.
- Nao usa instalacao global.
- Nao usa automacao cega.
- Tudo precisa ser audivel, local e reversivel.

## Como usar

1. Abrir o workflow certo para o tipo de tarefa.
2. Verificar o agente recomendado.
3. Rodar o checklist de entrada.
4. Trabalhar com o Codex CLI dentro do escopo autorizado.
5. Registrar checkpoint ou historico ao final.
6. Encerrar com checklist de saida.

## Integracoes

- Historico: registra a sessao e a retomada.
- Checkpoint: marca o ponto de continuidade.
- Status operacional: mostra o estado atual antes de comecar.
- Skills locais: entram como especialidades reutilizaveis.
- Comandos reutilizaveis e checklists: fecham validacao, seguranca e retomada.
- Obsidian: e a base de persistencia em Markdown.
- Codex CLI: e o executor principal.
- Inteligência do Cérebro: estuda memória, wiki viva, skills e autonomia segura.
