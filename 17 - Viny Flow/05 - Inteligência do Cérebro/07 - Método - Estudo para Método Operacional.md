# Método - Estudo para Método Operacional

TL;DR: use este método quando um estudo ainda não virou rotina, mas já mostra sinais de operação segura.

## Objetivo

Converter estudo em passo operacional mínimo, sem pular direto para automação.

## Quando usar

- Quando o tema já foi estudado, mas ainda não está pronto para rotina
- Quando existe repetição provável, mas faltam limites
- Quando a operação precisa nascer com guardrails

## Entrada esperada

- Estudo base
- Exemplo real
- Riscos
- O que já funciona
- O que ainda falta

## Passo a passo

1. Identificar a parte estável do estudo
2. Separar o que ainda é experimental
3. Definir uma execução mínima
4. Adicionar validação e reversão
5. Criar o método operacional

## Saída esperada

- Método curto
- Limites
- Sequência de uso
- Critérios de saída

## Checklist

- [ ] Parte estável identificada
- [ ] Parte experimental isolada
- [ ] Validação definida
- [ ] Risco de reversão definido
- [ ] Método mínimo escrito

## Riscos

- Promover estudo cedo demais
- Automatizar sem teste
- Criar método sem saída de segurança
- Misturar hipótese com rotina

## Prompt para usar no Codex

`Transforme este estudo em um método operacional mínimo, com limites, validação e reversão, sem tratá-lo como rotina pronta ainda.`

## Critérios de qualidade

- Pode ser executado manualmente
- Não depende de tooling externo
- Tem segurança explícita
- Mostra o que ainda é experimental
