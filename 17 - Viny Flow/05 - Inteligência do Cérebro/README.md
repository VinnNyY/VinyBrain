# Inteligência do Cérebro

Esta área estuda como transformar fontes externas em método operacional para o `Viny Brain`.

## O que entra aqui

- Pesquisa sobre padrões de wiki viva, memória em camadas e agentes
- Métodos para estudar, filtrar, compilar e auditar conhecimento
- Regras para autonomia segura sem instalar ferramentas externas agora
- Backlog de melhorias do cérebro e próximos experimentos

## O que esta área não faz

- Não instala ferramentas
- Não cria integração real
- Não chama API externa
- Não roda bootstrap
- Não salva credenciais

## Como usar

1. Ler a base de pesquisa
2. Escolher o método certo para o tipo de fonte
3. Compilar o método em regra operacional curta
4. Registrar riscos, limites e critérios de qualidade
5. Levar o resultado para o `Viny Flow` ou para o `MOC` quando virar padrão
