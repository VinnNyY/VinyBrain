# Método - Compilação LLM Wiki

TL;DR: use este método para transformar pesquisa em página viva, curta e auditável dentro do `Viny Brain`.

## Objetivo

Compilar estudo em uma página que um humano e um modelo consigam revisar rápido.

## Quando usar

- Quando a fonte já estiver filtrada
- Quando existir repetição suficiente para consolidar
- Quando o tema precisar virar referência viva

## Entrada esperada

- Tema central
- Fontes aprovadas
- Termos definidos
- Decisões recentes
- Perguntas em aberto

## Passo a passo

1. Definir o problema central
2. Escrever a explicação em Markdown simples
3. Criar seções de conceito, exemplos e limites
4. Adicionar links para páginas relacionadas
5. Registrar o que ficou fora

## Saída esperada

- Página de referência
- Conceitos definidos
- Links úteis
- Limites explícitos

## Checklist

- [ ] Título orientado ao problema
- [ ] TL;DR no topo
- [ ] Termos definidos
- [ ] Limites documentados
- [ ] Linkagem útil

## Riscos

- Página virar repositório de tudo
- Repetição sem ganho
- Conceito sem definição
- Link quebrado sem revisão

## Prompt para usar no Codex

`Compile esta pesquisa em uma página viva de wiki Markdown para o Viny Brain, com TL;DR, conceitos, limites e links úteis, sem inflar a página com ruído.`

## Critérios de qualidade

- Serve como referência
- Mostra limites
- É legível sem contexto externo
- Não mistura estudo com operação
