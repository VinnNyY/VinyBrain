# Mapa de Métodos

TL;DR: esta página mostra qual método usar em cada tipo de fonte, estudo ou decisão de arquitetura do cérebro.

## Visão geral

- [Método - Ingestão Inteligente de Fonte](./03%20-%20M%C3%A9todo%20-%20Ingest%C3%A3o%20Inteligente%20de%20Fonte.md): primeiro método da área, usar antes de transformar qualquer pesquisa em método, skill ou automação
- [Método - Compilação LLM Wiki](./04%20-%20M%C3%A9todo%20-%20Compila%C3%A7%C3%A3o%20LLM%20Wiki.md): usar para transformar pesquisa em página viva e navegável
- [Método - Geração de Skills Viny Flow](./05%20-%20M%C3%A9todo%20-%20Gera%C3%A7%C3%A3o%20de%20Skills%20Viny%20Flow.md): usar para decidir se um comportamento merece virar skill
- [Método - Auditoria de Conhecimento](./06%20-%20M%C3%A9todo%20-%20Auditoria%20de%20Conhecimento.md): usar para revisar qualidade, duplicidade e obsolescência
- [Método - Estudo para Método Operacional](./07%20-%20M%C3%A9todo%20-%20Estudo%20para%20M%C3%A9todo%20Operacional.md): usar para converter estudo em rotina segura
- [Método - Autonomia Segura](./08%20-%20M%C3%A9todo%20-%20Autonomia%20Segura.md): usar para definir o que já pode agir sozinho
- [Método - Radar GitHub Reddit e Docs](./09%20-%20M%C3%A9todo%20-%20Radar%20GitHub%20Reddit%20e%20Docs.md): usar para pesquisa recorrente de tendências e padrões
- [Método - Segurança para Skills e MCP](./10%20-%20M%C3%A9todo%20-%20Seguran%C3%A7a%20para%20Skills%20e%20MCP.md): usar para revisar riscos antes de qualquer expansão

## Critério de escolha

- Fonte nova ou solta: usar ingestão inteligente primeiro
- Pesquisa ainda sem destino: usar ingestão inteligente primeiro
- Fonte solta e pouco confiável: usar ingestão inteligente
- Pesquisa consolidada: usar compilação LLM Wiki
- Comportamento repetível: avaliar geração de skill
- Conhecimento em conflito: usar auditoria
- Estudo promissor, mas ainda frágil: usar estudo para método operacional
- Automação possível, mas arriscada: usar autonomia segura
- Tema externo em evolução: usar radar recorrente
- Entrada com risco técnico: usar segurança para skills e MCP
