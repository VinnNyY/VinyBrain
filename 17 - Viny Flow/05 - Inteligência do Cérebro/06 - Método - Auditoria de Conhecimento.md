# Método - Auditoria de Conhecimento

TL;DR: use este método para revisar se uma página ainda merece existir do jeito que está.

## Objetivo

Encontrar duplicidade, desatualização, lacuna e excesso de contexto.

## Quando usar

- Antes de consolidar uma área grande
- Quando uma wiki começar a crescer demais
- Quando houver dúvida sobre fonte de verdade

## Entrada esperada

- Área a auditar
- Páginas candidatas
- Sinais de duplicidade
- Sinais de obsolescência
- Necessidade de revisão humana

## Passo a passo

1. Listar páginas e temas
2. Marcar duplicatas
3. Marcar páginas fracas
4. Identificar links quebrados ou redundantes
5. Decidir manter, mesclar, mover ou arquivar

## Saída esperada

- Lista priorizada de ajustes
- Páginas para manter
- Páginas para fundir
- Páginas para revisar

## Checklist

- [ ] Duplicidade marcada
- [ ] Obsolescência marcada
- [ ] Fonte de verdade definida
- [ ] Ação sugerida
- [ ] Risco registrado

## Riscos

- Apagar referência útil
- Manter página velha como verdade
- Multiplicar versões sem controle
- Auditar sem critério único

## Prompt para usar no Codex

`Audite este conjunto de páginas e devolva duplicidades, obsolescências, lacunas e uma decisão clara de manter, fundir ou arquivar.`

## Critérios de qualidade

- Reduz ruído
- Explicita decisão
- Mantém rastreabilidade
- Preserva o que ainda é útil
