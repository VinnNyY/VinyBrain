# Decisoes do Viny Flow

Aqui ficam decisoes de arquitetura que ja foram tomadas.

## Decisoes atuais

- Viny Flow existe como camada local de orquestracao.
- Ruflo nao sera instalado como stack completo no Viny Brain agora.
- O sistema nao usa daemon como padrao.
- O sistema nao usa hooks agressivos como padrao.
- O sistema nao usa MCP como dependencia central.
- O sistema nao usa instalacao global.
- O sistema nao usa automacao cega.

## Regra

Se uma decisao mudar o modo de operar do vault, ela deve ser registrada aqui antes de virar pratica.
