# Browser Snippets

Snippets locais para leitura visual do `WHMCS` já aberto e logado.

## Arquivos

- [whmcs-scanner-visual-console.js](./whmcs-scanner-visual-console.js)
- [whmcs-scanner-visual-bookmarklet.js](./whmcs-scanner-visual-bookmarklet.js)

## Uso

- o snippet de console deve ser colado manualmente na página de tickets;
- o bookmarklet pode ser salvo como favorito no navegador;
- ambos leem apenas o DOM da página atual;
- nenhum deles acessa API, cookie, sessão ou armazenamento do navegador.
