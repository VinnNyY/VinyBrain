# Reports

Esta pasta armazena os relatorios gerados pelo detector local de ativacoes pendentes e a fila de aprovacao humana.

## Regras

- Relatorios sao gerados localmente em Markdown.
- A fila de aprovacao e exportada em Markdown, JSON e CSV.
- Nenhuma API real deve ser usada para criacao destes arquivos.
- Nenhuma credencial deve ser salva aqui.
- O conteudo deve permanecer livre de tokens, senhas, cookies e sessoes.
