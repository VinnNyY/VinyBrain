## Intencao de busca

Principal: solucao e consideracao comercial.

O usuario provavelmente tem uma base de codigo pouco documentada, herdada ou dificil de entender, e busca uma forma de gerar documentacao tecnica, reduzir dependencia de pessoas-chave ou acelerar onboarding.

Intencoes secundarias:

- Informacional: como documentar codigo legado.
- Comparativa: avaliar IA versus documentacao manual.
- Operacional: encontrar ferramenta para analisar repositorios e gerar documentacao.

## Recomendacoes tecnicas

- Um unico H1.
- HTML semantico.
- Title e meta description especificos.
- Canonical definido.
- Imagens com alt descritivo.
- Conteudo acima da dobra explicando produto, publico e beneficio.
- FAQ visivel na pagina e marcado com schema apenas se o texto estiver presente.
- Evitar JavaScript bloqueando renderizacao do conteudo principal.
- Carregar imagem hero/OG otimizada.
- Garantir responsividade e contraste.
- Incluir `robots` padrao index/follow apenas quando a pagina estiver pronta para publicacao.
- Nao publicar sem politica de privacidade se houver formulario, tracking ou coleta de leads.

## Checklist SEO

- [ ] Um H1 unico.
- [ ] Palavra-chave principal no H1 ou proxima do H1.
- [ ] Title com marca e termo principal.
- [ ] Meta description clara, sem promessa exagerada.
- [ ] Slug curto e descritivo.
- [ ] Canonical com dominio real.
- [ ] Open Graph completo.
- [ ] Imagem OG criada e otimizada.
- [ ] Alt texts especificos.
- [ ] Links internos definidos.
- [ ] FAQ visivel.
- [ ] Schema `SoftwareApplication` sem dados nao confirmados.
- [ ] Schema `FAQPage` alinhado ao conteudo real.
- [ ] Conteudo de origem academica em secao secundaria.
- [ ] Claims revisados antes da publicacao.
