# Prototipo isolado - Hero e Relatorio

Este prototipo valida apenas a direcao visual do hero e da secao de relatorio do Legacy Doc.

## Escopo

- Hero dark-first.
- Mockup HTML/CSS de codigo, analise e documentacao.
- Secao de relatorio em alto destaque.
- Motion leve com CSS.
- Responsividade basica.
- `prefers-reduced-motion`.

## Fora de escopo

- Landing completa.
- Integracao com backend.
- Captura real de leads.
- Funcionalidades reais de analise.
- Deploy.
- Claims comerciais.

## Como abrir

Abrir `index.html` diretamente no navegador.
