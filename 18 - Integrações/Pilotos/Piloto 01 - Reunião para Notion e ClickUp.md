# Piloto 01 - Reunião para Notion e ClickUp

## Objetivo do piloto

Este piloto serve para testar o fluxo manual de transformar uma reunião ou anotação solta em:

- página pronta para `Notion`;
- tarefas prontas para `ClickUp`;
- decisões registradas no `Viny Brain`;
- pendências e follow-ups organizados.

## Entrada bruta

Cole aqui as anotações soltas da reunião.

```txt

Participantes:
Contexto:
Anotações:
Decisões:
Pendências:
Prazos:
Responsáveis:
Links úteis:
```

- nome da tarefa;

## Como usar o piloto

1. Cole a reunião bruta.
2. Preencha a saída para Notion.
3. Separe as tarefas que vão para ClickUp.
4. Registre só o necessário no Viny Brain.
5. Use a tabela de pendências para follow-up.
6. Revise a segurança antes de usar qualquer dado real.

## Como validar se o piloto funcionou

- Notion recebeu uma página clara;
- ClickUp recebeu tarefas acionáveis;
- Viny Brain manteve a decisão principal;
- não houve duplicidade desnecessária;
- fonte da verdade ficou clara;
- próximos passos ficaram claros.

## Fonte da verdade

- `Viny Brain`: decisões, contexto, riscos e histórico.
- `Notion`: versão compartilhável da reunião.
- `ClickUp`: execução e acompanhamento das tarefas.

## Observações de segurança

- Não registrar tokens, senhas, IPs sensíveis ou dados reais de cliente.
- Não colar prints com informações sensíveis.
- Se houver dúvida, manter no `Viny Brain` até revisão.
- Este arquivo é apenas um modelo manual.

## Prompt reutilizável
