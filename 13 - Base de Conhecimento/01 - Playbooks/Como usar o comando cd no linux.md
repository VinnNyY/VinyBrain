## Resumo Objetivo

- Explicar o uso básico do `cd` para navegação entre diretórios no Linux.

## Quando Usar

- Quando for entrar em uma pasta específica.
- Quando for voltar um nível na estrutura de diretórios.
- Quando for necessário retornar para a pasta principal do usuário.

## Pré-requisitos

- Ter acesso ao terminal Linux.
- Saber qual diretório precisa ser acessado.
- Entender se o caminho tem espaços ou caracteres especiais.

## Passo a Passo Interno

1. Usar `cd` para entrar no diretório necessário.
2. Usar o caminho completo quando houver dúvida sobre a localização.
3. Voltar um nível quando for preciso corrigir a navegação.
4. Retornar ao diretório inicial quando quiser recomeçar.
5. Confirmar a localização antes de seguir para a próxima ação.

## Resposta / Orientação Possível para Cliente

- Informar que o comando serve para trocar de pasta no terminal.
- Explicar que ele ajuda a chegar no local correto antes de executar qualquer outra ação.
- Manter a explicação curta e objetiva.

## Pontos de Atenção

- Não executar comandos no diretório errado.
- Não confundir caminho relativo com caminho absoluto.
- Não esquecer de validar a pasta atual antes de prosseguir.

## Erros Comuns

- Digitar o caminho incompleto.
- Esquecer aspas quando houver espaço no nome da pasta.
- Tentar operar sem confirmar a localização atual.
