## Diagnóstico rápido

- Use este playbook quando o problema for acesso ao Webmail ou contas de e-mail dentro do cPanel.
- Se o problema estiver em Outlook ou Gmail, trate isso como cliente de e-mail antes de mudar o painel.
- Se o e-mail não chega, este playbook pode ser só a porta de entrada para o diagnóstico, não a solução final.

## Quando Usar

- Quando o cliente precisa acessar a conta de e-mail pelo cPanel/Webmail.
- Quando for orientar configuração básica do acesso da conta.

## Causas comuns

- Credenciais incorretas.
- Caixa criada, mas acesso não configurado corretamente.
- Cliente usando o app errado.
- Falha de acesso por hostname, senha ou permissões.

## Pré-requisitos

- Validar o documento original no Google Docs antes de usar como procedimento final.
- Confirmar qual conta será acessada.
- Saber se o acesso será Webmail, IMAP ou cliente local.

## Passo a Passo Interno

1. Confirmar a conta de e-mail e o domínio.
2. Abrir a área correta no cPanel.
3. Validar credenciais e tipo de acesso.
4. Orientar o uso do Webmail quando a validação inicial for necessária.
5. Registrar se o acesso depende de IMAP ou de outro cliente.

## Passo a passo seguro

1. Testar o acesso no Webmail antes de alterar o cliente local.
2. Não passar credencial em texto desnecessário.
3. Não confundir problema de acesso com problema de entrega.
4. Se o acesso falhar no cPanel, revisar a conta e o status do serviço.

## Resposta / Orientação Possível para Cliente

- Pendente de revisão. Não usar como texto final para cliente até validar a fonte.

## O que NÃO fazer

- Não orientar configuração sem saber se a conta existe.
- Não mexer no cliente local sem validar o Webmail.
- Não assumir que o problema é do Outlook/Gmail sem teste.

## Quando escalar

- Quando o Webmail não abre mesmo com a conta criada corretamente.
- Quando houver falha no serviço, bloqueio ou suspeita de conta ausente.
- Quando a orientação depender de validação técnica mais profunda.

## Pontos de Atenção

- Não tratar este arquivo como versão final do procedimento.
- Revisar o Google Docs original antes de aplicar em atendimento.

## Erros Comuns

- Usar o resumo como se fosse o conteúdo completo.
- Ignorar o status de revisão pendente.
