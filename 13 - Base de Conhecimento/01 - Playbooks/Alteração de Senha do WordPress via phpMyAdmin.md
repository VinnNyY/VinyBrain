## Resumo Objetivo

- Registrar a troca de senha de acesso ao WordPress quando o acesso normal ao painel não estiver disponível.

## Quando Usar

- Quando o usuário não conseguir entrar no WordPress.
- Quando for preciso recuperar acesso com segurança.
- Quando a alteração precisar ser feita pela interface do banco.

## Pré-requisitos

- Confirmar que o acesso ao banco é autorizado.
- Saber qual usuário do WordPress será ajustado.
- Ter cuidado para não alterar a conta errada.

## Passo a Passo Interno

1. Identificar a base de dados correta.
2. Localizar o usuário que precisa do ajuste.
3. Redefinir a senha pela interface apropriada.
4. Validar o novo acesso no WordPress.
5. Registrar a alteração sem expor a credencial.

## Resposta / Orientação Possível para Cliente

- Informar que o acesso foi recuperado por um procedimento seguro.
- Explicar que a senha precisa ser trocada com responsabilidade.
- Evitar mencionar valores de senha ou detalhes sensíveis.

## Pontos de Atenção

- Não editar o usuário incorreto.
- Não registrar senha em local persistente.
- Não misturar recuperação com outra alteração de banco.

## Erros Comuns

- Trocar a senha do usuário errado.
- Não confirmar o login depois da alteração.
- Expor credenciais no registro do atendimento.
