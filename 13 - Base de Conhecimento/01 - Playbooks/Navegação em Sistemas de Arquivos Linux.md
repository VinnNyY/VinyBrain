## Resumo Objetivo

- Padronizar a navegação básica por diretórios em Linux para suporte e operação.

## Quando Usar

- Quando for localizar arquivos, logs ou pastas do sistema.
- Quando o caminho informado pelo cliente estiver incompleto.
- Quando for preciso orientar alguém a chegar no diretório correto antes de operar.

## Pré-requisitos

- Ter acesso ao terminal Linux.
- Saber qual diretório ou arquivo precisa ser encontrado.
- Entender se o caminho é absoluto ou relativo.

## Passo a Passo Interno

1. Confirmar o diretório atual antes de navegar.
2. Ir para a pasta correta usando o caminho adequado.
3. Listar o conteúdo para validar se o alvo está no local esperado.
4. Ajustar a navegação até o diretório final.
5. Registrar o caminho usado quando isso for útil para o caso.

## Resposta / Orientação Possível para Cliente

- Explicar que a navegação em pastas serve para localizar arquivos e logs.
- Pedir que o cliente informe o caminho, nome do arquivo ou contexto do caso.
- Manter a explicação simples e sem jargão desnecessário.

## Pontos de Atenção

- Não operar no diretório errado.
- Não confundir caminho absoluto com caminho relativo.
- Não excluir nada durante a etapa de localização.

## Erros Comuns

- Perder a referência do diretório atual.
- Tentar abrir um caminho que não existe.
- Executar ações de manutenção sem confirmar a pasta correta.
