# Regras para BKPs

BKPs são materiais de apoio, referência ou backup da base de conhecimento.

## O que entra como BKP

Entram aqui conteúdos que:
- servem como rascunho ou base técnica
- registram variações de um processo
- funcionam como referência de apoio
- preservam material útil para consulta futura

## O que não entra como BKP

Não tratar como BKP:
- tutorial final
- playbook consolidado
- relatório
- conteúdo pronto para cliente sem necessidade de apoio

## Estrutura esperada

Todo BKP deve, quando possível, registrar:
- título
- origem
- finalidade
- status
- link original
- observações

## Como classificar

Use a classificação `BKP` quando o documento:
- for apoio técnico
- servir como backup de informação
- ajudar na reconstrução de processo
- ainda não representar a versão final principal

## Como usar links

Se o BKP vier de um documento externo:
- preservar o link original
- registrar a fonte
- manter o material apenas como referência

## Como usar na prática

BKPs servem para:
- consultar histórico
- recuperar informação
- comparar versões
- apoiar revisão de tutoriais e playbooks
- guardar materiais complementares

## Regra importante

Se o conteúdo virar referência principal, ele pode deixar de ser BKP e passar a playbook, tutorial ou norma, conforme o caso.
