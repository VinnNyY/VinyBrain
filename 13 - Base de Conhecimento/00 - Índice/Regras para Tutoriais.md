# Regras para Tutoriais

Tutoriais são documentos orientados ao usuário final ou a uma explicação prática de uso.

## O que entra como Tutorial

Entram aqui conteúdos que:
- explicam passo a passo
- ajudam o cliente a resolver uma dúvida
- têm linguagem simples e direta
- podem ser publicados na base de ajuda

## O que não entra como Tutorial

Não tratar como tutorial:
- playbook interno
- bkp técnico
- relatório
- documento administrativo
- anotações sem sequência prática

## Estrutura esperada

Todo tutorial deve, quando possível, ter:
- título
- objetivo
- público-alvo
- pré-requisitos
- passo a passo
- resultado esperado
- erros comuns
- observações

## Como classificar

Use a classificação `Tutorial` quando o documento:
- tiver linguagem voltada ao cliente
- explicar uma ação prática
- puder ser publicado externamente
- tiver valor de base de conhecimento pública

## Como usar links

Se o tutorial já estiver publicado:
- registrar o link da publicação
- manter o texto original como referência
- não apagar a relação com a fonte interna, se existir

Se o tutorial ainda estiver em revisão:
- manter o status correto
- não tratar como final enquanto estiver pendente

## Como usar na prática

Tutoriais servem para:
- responder perguntas frequentes
- reduzir repetição no suporte
- orientar clientes com clareza
- servir de base para novos conteúdos

## Regra importante

Se houver dúvida entre tutorial e playbook:
- se for para cliente, use Tutorial
- se for para equipe, use Playbook
