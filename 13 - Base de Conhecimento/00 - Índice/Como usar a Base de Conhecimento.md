# Como usar a Base de Conhecimento

Este documento explica como a base de conhecimento deve funcionar dentro do vault.

## Papel da planilha

A planilha `Conteudos - Base de conhecimento` é o índice mestre da base.

Ela serve para:
- listar todo o conteúdo relevante
- registrar tipo, status, autor e link original
- separar o que já foi publicado do que ainda está pendente
- apontar para materiais internos e externos

## Como a planilha deve ser interpretada

### `Playbook`
Conteúdo interno, voltado para orientar execução, processo ou suporte.

### `Tutorial`
Conteúdo publicado ou em formato de passo a passo, normalmente voltado ao cliente ou ao usuário final.

### `BKP` ou backup
Material de apoio, referência técnica, rascunho reaproveitável ou documentação que serve como base.

### `Norma` ou procedimento interno
Conteúdo que define regra, padrão, conduta ou fluxo interno.

### `Pendente`
Conteúdo que ainda não deve ser tratado como versão final.

### `Postado`
Conteúdo já publicado ou consolidado no formato esperado.

## Como consultar links

Quando a planilha trouxer um link:
- manter o link original como fonte
- abrir o link apenas quando houver necessidade de validar contexto, fluxo ou linguagem
- não substituir o endereço original por cópias locais

## Quando acessar links internos

Acessar os links internos quando for necessário:
- confirmar um procedimento
- validar a versão correta do conteúdo
- comparar material interno com material publicado
- entender o fluxo antes de responder uma dúvida
- transformar uma nota solta em documento estruturado

## Como separar conteúdo interno de conteúdo para cliente

### Conteúdo interno
Usar quando o material:
- explica operação interna
- contém fluxo de suporte
- orienta equipe
- registra processo ou padrão interno

### Conteúdo para cliente
Usar quando o material:
- explica um passo a passo público
- resolve dúvida recorrente do cliente
- pode ser publicado na base de ajuda
- tem linguagem simples e orientada ao usuário final

## Como usar isso no trabalho

Use a base para:
- responder dúvidas com mais precisão
- criar tutoriais consistentes
- gerar relatórios com referência real
- comparar versões de um mesmo processo
- reaproveitar conteúdo já validado

## Regra principal

Antes de criar conteúdo novo, verifique se já existe uma referência no índice mestre.
Se existir, use como base.
Se não existir, registre a nova entrada com o status correto.
